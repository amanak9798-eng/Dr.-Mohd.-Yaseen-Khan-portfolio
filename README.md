# Dr. Mohd. Yaseen Khan - Academic Portfolio

## Overview
This is a multi-page, animated academic portfolio website for Dr. Mohd. Yaseen Khan.

## How to View
Simply open `index.html` in any modern web browser.

## Structure
- `index.html`: Home page with Hero section.
- `about.html`: Academic narrative and Expertise.
- `education.html`: Educational timeline.
- `experience.html`: Professional experience timeline.
- `research.html`: Publications and research interests.
- `awards.html`: Awards and recognitions.
- `gallery.html`: Photo gallery (placeholders).
- `contact.html`: Contact form and details.
- `css/style.css`: Main stylesheet.
- `js/animations.js`: GSAP animations.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- GSAP (via CDN)
